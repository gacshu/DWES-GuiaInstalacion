DWES · Práctica de servidor

Ubuntu Server + Apache + FTP + PHP-FPM

Guía unificada para crear una máquina virtual con Ubuntu Server, instalar Apache, configurar FTP, mover el proyecto web a /home/usuario/web, instalar PHP-FPM y comprobarlo con un PHP sencillo.

1. Preparar la máquina virtual

Instala un programa de virtualización en el ordenador anfitrión. VirtualBox es una opción válida en Windows, Linux y macOS.

Descarga la imagen ISO de Ubuntu Server 24.04 LTS. En equipos Intel/AMD utiliza la imagen AMD64. En Mac con Apple Silicon utiliza una imagen ARM64 y un hipervisor compatible.

Configuración recomendada de la VM

RecursoValor recomendado
CPU2 núcleos
RAM2–4 GB
Disco25 GB dinámicos
RedAdaptador puente, o NAT + redirección de puertos

2. Instalar Ubuntu Server

  1. Arranca la VM con la ISO de Ubuntu Server montada.
  2. Selecciona idioma y teclado.
  3. Configura la red por DHCP, salvo que necesites IP fija.
  4. Usa el disco virtual completo para la instalación.
  5. Crea un usuario, por ejemplo alumno.
  6. Marca Install OpenSSH server si quieres administrar la VM por SSH.
  7. Finaliza la instalación y reinicia.

Tras iniciar sesión, actualiza el sistema:

sudo apt update
sudo apt upgrade -y

3. Configurar la red para acceder desde el ordenador

La opción más sencilla para una práctica es Adaptador puente. La VM recibirá una IP de la misma red que el ordenador anfitrión.

Consulta la IP:

ip a
hostname -I

Ejemplo:

192.168.1.80

Desde el navegador del ordenador anfitrión usarás:

http://192.168.1.80

4. Instalar Apache

sudo apt install apache2 -y
sudo systemctl enable --now apache2
sudo systemctl status apache2

Comprueba desde el ordenador anfitrión:

http://IP_DE_LA_VM

Si aparece la página por defecto de Apache, el servidor web funciona.

5. Mover el proyecto de Apache a /home/usuario/web

Sustituye usuario por el usuario real de Ubuntu. En los ejemplos se utilizará alumno.

5.1 Crear la carpeta

mkdir -p /home/alumno/web

5.2 Permitir que Apache pueda atravesar el directorio personal

Apache se ejecuta con el usuario www-data. Aunque la carpeta web tenga permisos correctos, Apache debe poder atravesar /home/alumno.

chmod 711 /home/alumno

711 permite atravesar el directorio sin permitir que otros usuarios listen su contenido.

5.3 Permisos del proyecto

sudo chown -R alumno:alumno /home/alumno/web
find /home/alumno/web -type d -exec chmod 755 {} \;
find /home/alumno/web -type f -exec chmod 644 {} \;
Evita chmod -R 777. No es necesario y concede permisos de escritura a cualquier usuario.

5.4 Configurar Apache

Crea un sitio propio:

sudo nano /etc/apache2/sites-available/dwes.conf

Contenido:

<VirtualHost *:80>
    ServerName localhost
    DocumentRoot /home/alumno/web

    <Directory /home/alumno/web>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/dwes_error.log
    CustomLog ${APACHE_LOG_DIR}/dwes_access.log combined
</VirtualHost>

Activa el sitio y desactiva el predeterminado:

sudo a2dissite 000-default.conf
sudo a2ensite dwes.conf
sudo apache2ctl configtest
sudo systemctl reload apache2

5.5 Crear una página HTML de prueba

echo '<h1>Servidor DWES funcionando</h1>' > /home/alumno/web/index.html

Abre:

http://IP_DE_LA_VM

6. Instalar y configurar FTP

Para la práctica se puede utilizar vsftpd:

sudo apt install vsftpd -y
sudo systemctl enable --now vsftpd
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.backup
sudo nano /etc/vsftpd.conf

Comprueba o añade estas opciones:

anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES
allow_writeable_chroot=YES

Reinicia el servicio:

sudo systemctl restart vsftpd
sudo systemctl status vsftpd

Desde un cliente FTP utiliza:

DatoValor
ServidorIP de la VM
Puerto21
Usuarioalumno
Contraseñala contraseña del usuario
FTP clásico no cifra credenciales ni datos. Para uso real, utiliza SFTP sobre SSH. Aquí FTP se emplea con finalidad didáctica.

7. Instalar PHP-FPM

No necesitas instalar primero mod_php. Si vas a usar PHP-FPM, puedes instalar directamente PHP-FPM y PHP CLI con las extensiones necesarias.

En Ubuntu Server 24.04 la versión habitual es PHP 8.3:

sudo apt install php8.3-fpm php8.3-cli php8.3-curl php8.3-mbstring php8.3-xml php8.3-zip -y

Comprueba la versión:

php -v

Activa PHP-FPM:

sudo systemctl enable --now php8.3-fpm
sudo systemctl status php8.3-fpm

PHP-FPM escucha normalmente mediante un socket Unix:

ls -l /run/php/php8.3-fpm.sock

8. Configurar php.ini para mostrar errores en pantalla

Mostrar errores en pantalla es útil durante el desarrollo, pero no debe dejarse activo en producción: los mensajes pueden revelar rutas, consultas y datos internos del servidor.

Como Apache está conectado con PHP-FPM, debes editar el php.ini de FPM, no solo el de PHP CLI:

sudo nano /etc/php/8.3/fpm/php.ini

Busca estas directivas y déjalas así (si empiezan por ;, quita el punto y coma):

display_errors = On
display_startup_errors = On
error_reporting = E_ALL

Guarda el archivo y reinicia PHP-FPM para aplicar los cambios:

sudo systemctl restart php8.3-fpm
sudo systemctl reload apache2

Comprobar que se muestran los errores

Crea temporalmente un archivo de prueba:

nano /home/alumno/web/errores.php

Escribe este contenido:

<?php
echo $variable_que_no_existe;
echo '<p>Si ves un aviso de PHP, la configuración funciona.</p>';

Abre http://IP_DE_LA_VM/errores.php. Deberías ver el aviso de PHP en la página.

Cuando termines las pruebas, elimina el archivo y desactiva la visualización en pantalla: 
rm /home/alumno/web/errores.php
sudo nano /etc/php/8.3/fpm/php.ini
display_errors = Off
display_startup_errors = Off
error_reporting = E_ALL
log_errors = On

Después aplica de nuevo el cambio:

sudo systemctl restart php8.3-fpm

9. Conectar Apache con PHP-FPM

Apache debe enviar los archivos PHP al proceso PHP-FPM mediante FastCGI.

sudo a2enmod proxy_fcgi setenvif
sudo a2enconf php8.3-fpm
sudo apache2ctl configtest
sudo systemctl restart apache2

Comprueba que los módulos están activos:

apache2ctl -M | grep -E 'proxy_fcgi|setenvif'

Y que la configuración de FPM está habilitada:

ls -l /etc/apache2/conf-enabled/php8.3-fpm.conf
Flujo de la petición: Navegador → Apache → PHP-FPM → Apache → Navegador.

10. Crear un PHP sencillo para probar PHP-FPM

Elimina o renombra temporalmente el index.html para que Apache pueda mostrar index.php:

mv /home/alumno/web/index.html /home/alumno/web/index.html.bak

Crea:

nano /home/alumno/web/index.php

Contenido:

<?php
$nombre = 'DWES';

echo '<h1>PHP-FPM funciona</h1>';
echo '<p>Servidor: ' . htmlspecialchars($nombre) . '</p>';
echo '<p>Versión PHP: ' . PHP_VERSION . '</p>';
echo '<p>Fecha del servidor: ' . date('d/m/Y H:i:s') . '</p>';

Desde el ordenador anfitrión abre:

http://IP_DE_LA_VM/

Deberías ver el mensaje PHP-FPM funciona, la versión de PHP y la fecha del servidor.

Comprobación adicional

También puedes crear temporalmente:

echo '<?php phpinfo(); ?>' > /home/alumno/web/info.php

Abre:

http://IP_DE_LA_VM/info.php

Busca Server API. Debe aparecer una referencia a FPM/FastCGI.

Después de comprobarlo, elimina info.php, ya que revela mucha información del servidor: 
rm /home/alumno/web/info.php

11. Comprobaciones y problemas frecuentes

Apache no abre desde el ordenador

sudo systemctl status apache2
hostname -I

Comprueba también que la VM está en modo puente o que tienes configurada la redirección de puertos.

Error 403 Forbidden

namei -l /home/alumno/web
ls -ld /home/alumno
ls -ld /home/alumno/web

El directorio personal debe permitir el paso a Apache, y el bloque <Directory> debe incluir Require all granted.

Los PHP se descargan o se muestran como texto

sudo systemctl status php8.3-fpm
sudo a2enmod proxy_fcgi setenvif
sudo a2enconf php8.3-fpm
sudo systemctl restart apache2

Error 500

Consulta los logs:

sudo tail -f /var/log/apache2/dwes_error.log
sudo journalctl -u php8.3-fpm -f

Comprobar configuración de Apache

sudo apache2ctl configtest

Reiniciar servicios

sudo systemctl restart apache2
sudo systemctl restart php8.3-fpm
sudo systemctl restart vsftpd

Resultado final

Al terminar tendrás:

  • Ubuntu Server ejecutándose en una máquina virtual.
  • Apache accesible desde el ordenador anfitrión.
  • El proyecto web en /home/alumno/web.
  • FTP mediante vsftpd para transferir archivos.
  • PHP 8.3 ejecutándose mediante PHP-FPM.
  • Apache conectado con PHP-FPM mediante FastCGI.
  • Un index.php sencillo funcionando desde el navegador.
